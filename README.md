# AI Engineer Roadmap | رحلة تعلم هندسة الذكاء الاصطناعي

هذا المشروع مساحة تدريب عملية لتقوية كتابة Python وبناء أنظمة AI خطوة بخطوة. لديك تدريب سابق وفهم لـRAG؛ سنعيد بناء الأساس العملي بسرعة مناسبة لمستواك. نقطة البداية هي كتابة كود صغير بنفسك؛ كل تمرين مرتبط بعمل قد تحتاجه في RAG أو FastAPI أو PostgreSQL وpgvector أو Agents أو تقييم الأنظمة.

## طريقة العمل

1. افتح [خطة الرحلة](ROADMAP.md) و[خريطة مهارات Python](PYTHON_SKILLS.md) لمعرفة الاتجاه العام وما تحتاج إتقانه.
2. نفّذ **المهمة الحالية فقط** في مجلد `lessons/`.
3. شغّل الكود، ثم أرسل محاولتك أو رسالة الخطأ للمراجعة.
4. بعد نجاح المهمة، نحدّث [سجل التقدم](PROGRESS.md) ونفتح المهمة التالية.

سأشرح المفهوم وأراجع محاولتك وأعطي تلميحات تدريجية. لن أضع حلول التمارين قبل محاولتك، إلا إذا طلبت ذلك صراحة. لا يلزم حفظ كل أوامر Python؛ المطلوب فهم الكود والقدرة على كتابته وتصحيح أخطائه.

## الآن

المهمة الحالية: [01 — التعامل مع chunks](lessons/01_chunks/README.md).

شغّل ملف البداية من جذر المشروع باستخدام Python 3.11 أو أحدث:

```powershell
python lessons/01_chunks/starter.py
```

لا يحتاج هذا التمرين إلى تثبيت أي مكتبة. سنضيف الأدوات والاعتماديات عند الوصول إليها.
